# 2M-Flores-ASL text snapshot

Acquired from the official facebook/2M-Flores-ASL dataset-server projection.
Source: https://huggingface.co/datasets/facebook/2M-Flores-ASL
License: Creative Commons Attribution-ShareAlike 4.0.
Citation: 2M-BELEBELE: Highly-Multilingual Speech and American Sign Language
Comprehension Dataset (Costa-jussà et al., 2024), as specified by the dataset card.
https://arxiv.org/abs/2412.08274

Only id, source URL, domain, topic, English sentence, gloss and local signer ID
were retained. No video payload was acquired. `provenance.json` contains the source
revision and file checksums. See ../../README.md for preprocessing and usage.
