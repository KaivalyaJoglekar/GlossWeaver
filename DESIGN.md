# GlossWeaver 2.0 design

Dark graphite laboratory with restrained cyan actions. Main #080A0F, secondary #0D1119, elevated #131923, border #252D38, text #F3F6FA, muted #9DA8B8, accent #7CEBFF. System sans for interface and editorial hero; monospace for checkpoint IDs and metrics. Fine borders, 5–12px radii, no decorative card shadows.

Persistent desktop sidebar collapses to icons; below 768px it becomes wrapping compact navigation. Studio panes stack below 900px. Native labeled controls, disabled unavailable checkpoints, keyboard shortcuts, visible focus, skip link, live request states, reduced motion, and 44px ordinary action targets. Text resolution animation runs once when a real result arrives and leaves a readable sentence; it depicts an edit metaphor.

Overview introduces the transformation motif and actual service status. Studio and Comparison carry real checkpoint identities and advisory preservation diagnostics. Research separates historical scores, development diagnostics, and current matched-study infrastructure. Tables scroll within their containers; filters and metric controls remain accessible. The Research bundle loads separately.

## Black refinement

The current user requested true black, overriding the earlier graphite palette. Canvas #000000, surface #080808, elevated #151515, input #090909, borders #242424/#343434. Neutral white primary actions and restrained pale-cyan identity/focus; semantic colors remain reserved for actual diagnostics. Shared 5/8/12px radius scale. Radix icons replace navigation glyphs without changing navigation labels or routes.

The Overview uses a split composition above 1120px and explicitly stacks below it. Hero copy stays under 20 words, with both actions visible in the first desktop viewport. Mobile uses compact wrapping navigation. Studio typography and spacing are refined across black surfaces. Pointer results fade for 180ms; keyboard results appear instantly. Removed the scan and blur choreography. Press feedback uses a 140ms ease-out curve and is disabled for keyboard focus and reduced motion. No new animation library is needed.
